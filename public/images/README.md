# Image Assets

Place image files here for the Convivium website.

## Recommended Organization

```
images/
  hero/           # Homepage hero/header images
  about/          # About section images
  music/          # Album art, promotional photos
  thumbnails/     # Video thumbnails
  icons/          # Small UI icons
```

## Supported Formats
- Use WebP or optimized JPG/PNG
- Next.js Image component will auto-optimize
- Keep originals high-res (Next.js will generate responsive sizes)
